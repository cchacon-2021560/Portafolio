# Portafolio

Portafolio de desarrollador profesional.

## Stack

- **Frontend**: React + Vite + Tailwind CSS + Framer Motion + react-icons
- **Backend**: Node.js + Express + Nodemailer (microservicio de contacto)

## Inicio rápido

```bash
pnpm install
pnpm run dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:3001
